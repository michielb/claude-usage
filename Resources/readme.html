Before you begin

This app requires Claude Code (the CLI tool) with an active login. It works with Claude Max, Pro, and Team plans.

Setup

  1. Install Claude Code if you haven't already
  2. Open Terminal and run: claude
  3. Sign in with your Anthropic account
  4. Launch ClaudeUsage —it will appear in your menu bar

Keychain Access

On first launch, macOS will ask you to allow ClaudeUsage to access your Claude Code credentials in the Keychain. This is required for the app to read your usage data. The credentials are only used to call the Anthropic usage API —nothing is stored or sent elsewhere.

Features

  • Menu bar —live progress bars for 5-hour and 7-day usage
  • HUD overlay —floating panel you can toggle on/off
  • Compact mode —for smaller screens or crowded menu bars
  • Launch at Login —optional, toggle in the dropdown
